# NYC Yellow Taxi Trip Analytics Project

This project aim is to identify busy hours and zones, and summarize trip duration, distance and fares using the 
January 2025 Yellow Taxi trip records in Parquet along with the Taxi Zone Lookup CSV from the [official TLC data page](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page?utm_source=chatgpt.com).

## Project Status

The project is in its initial stages that focus on setting up the environment and acquiring the data.
